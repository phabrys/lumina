# Lumina

Intégration Home Assistant de gestion automatique des lumières et ventilateurs **par pièce**, avec prise en compte de la présence et de la luminosité.

Chaque pièce est une entrée de configuration indépendante, ajoutée depuis l'interface de Home Assistant : aucune automatisation à écrire ou à dupliquer.

> Projet en cours de développement.
